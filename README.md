# Myntra Clone 👗🛒

## 🚀 Overview
A front‑end clone of Myntra built using **HTML, CSS, and JavaScript**.  
It replicates the shopping experience with product listings, shopping bag functionality, and a responsive design.

## ✨ Features
- Product catalog powered by `data/items.js`
- Shopping bag page (`pages/bag.html`)
- Add to bag functionality (`scripts/bag.js`)
- Responsive styling (`css/index.css`, `css/bag.css`)
- Clean UI with images and assets
